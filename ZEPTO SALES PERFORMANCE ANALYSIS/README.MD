Project Title: Zepto Sales Performance Analysis

Overview:
This project is a Power BI dashboard created to analyze key performance metrics for Zepto. The goal of the dashboard is to convert raw data into meaningful insights that help in understanding sales, operations, delivery performance, and customer behavior.

Project Description:
The Power BI report includes multiple pages with visualizations that highlight trends, comparisons, and KPIs. It is designed for business decision-making and provides a clear view of overall performance. The project involves data cleaning, data modeling, DAX calculations, and interactive visuals.

Key Features:

Interactive dashboard pages with slicers for easy filtering.

Clean and optimized data model using Power Query transformations.

DAX measures created for KPIs such as Total Orders, Revenue, Average Delivery Time, Repeat Customers, and Time-Based Metrics.

Visual insights showing trends, category comparisons, and performance breakdown.

User-friendly layout designed for quick analysis.

Tools Used:
Power BI Desktop
Power Query
DAX
Excel or CSV data sources

Project File:
Zepto PowerBI Project.pbix contains the complete dashboard, visuals, data model, and transformations.

How to Use:
Download the PBIX file.
Open the file in Power BI Desktop.
Refresh the data if required.
Use slicers and visuals to explore insights.

Outcomes:
This project demonstrates the ability to build business dashboards, create DAX measures, model data effectively, and present insights that support decision-making.
